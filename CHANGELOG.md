# Changelog

## 0.2.0

- Added Linked and Managed Workspaces with revision-checked multi-file edits.
- Added the pinned ESM/TypeScript builder for WebGL, WebGPU, TSL, shaders, and
  revision-bound assets.
- Added the isolated Workspace Runtime with edit/run modes, diagnostics,
  Runtime Harness evidence, and deterministic teardown.
- Added Scene projection, Properties, TransformControls, parameters, debug
  modes, and persistent human/AI edit continuity.
- Added verified compatibility for post-processing, GLTF/Draco/KTX2,
  animation, gameplay physics, audio, and advanced GPU cases.
- Added the community `case.json` validator, capture runner, compatibility
  metadata, and contributor, migration, dependency, and security guides.
- Preserved V1 Scene projects and existing Runtime wire identifiers.

## 0.1.0

- Initial MCP Server, MCP App editor, Scene project lifecycle, Pong template,
  bounded assets, diagnostics, and JSON export.
